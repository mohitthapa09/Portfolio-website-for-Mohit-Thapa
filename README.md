# 🌐 Personal Portfolio Website — Mohit Thapa

**Live Demo:** [mohitthapa09.github.io/Portfolio-website-for-Mohit-Thapa](https://mohitthapa09.github.io/Portfolio-website-for-Mohit-Thapa/)

A sleek, responsive, and modern personal portfolio website built with clean HTML5 and CSS3. Designed with a dark-mode aesthetic, vibrant gradients, dynamic smooth scrolling, and custom UI components to showcase academic background, technical skills, machine learning & web projects, and direct contact options.

---

## 📌 Project Overview

This website serves as a central hub for **Mohit Thapa**, a computer applications student specializing in **Artificial Intelligence & Data Science**. It is crafted to deliver a fast, lightweight, and engaging user experience across all device sizes—from mobile phones to desktop screens—without relying on heavy third-party framework overhead.

### 👥 Target Audience
- **Recruiters & Hiring Managers:** Looking for software engineering, web development, or AI/DS interns.
- **Collaborators & Open Source Contributors:** Seeking project partners in machine learning and web platform development.
- **Academic Peers & Instructors:** Reviewing project showcases and academic achievements.

---

## 🚀 Key Features

- **Interactive Navigation Bar:** Smooth-scrolling page links with dynamic hover underline effects and a responsive mobile burger menu.
- **Hero & Personal Introduction:** High-impact hero section featuring personal branding, custom typography, quick social links, and an interactive portrait frame with an animated orb glow.
- **About Me Section:** Background summary detailing academic focus, core software philosophy, and problem-solving goals in AI/Data Science.
- **Interactive Education Timeline:** A styled vertical timeline outlining educational history from secondary education to undergraduate studies and diploma certifications.
- **Categorized Skills Matrix:** Interactive skill cards categorized into Programming, AI/DS, Tools, Full Stack Web, Core CS Concepts, and Soft Skills.
- **Project Showcase Deck:** Clean grid highlighting featured applications (such as *AgriVision AI — Crop Analytics* and *ATN Workspace*), complete with hover elevation, live project links, and technology stack tags.
- **Contact & Resume Download:** Direct email/social interaction links alongside an embedded resume distribution button.

---

## 🛠️ Technology Used

- **HTML5:** Built with semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) for structure, SEO, and accessibility.
- **CSS3:** Built without heavy external frameworks using modern techniques:
  - **CSS Grid & Flexbox:** Fully responsive page layouts.
  - **CSS Custom Properties (`var(--...)`):** Centralized design tokens for colors, spacing, and dark mode styling.
  - **CSS Animations & Keyframes:** Dynamic background glowing orbs and smooth hover states.
- **CI/CD & Automation:** **GitHub Actions** (`.github/workflows`) configured for automated site building and continuous deployment.
- **Assets & Typography:** **Google Fonts** and **Font Awesome v6.5** for vector iconography and web typography.
- **Hosting & Version Control:** Version controlled via **Git** and hosted live on **GitHub Pages**.
